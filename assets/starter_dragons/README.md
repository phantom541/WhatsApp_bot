# Starter dragon images

Upload the starter dragon images to this folder as PNG files using these exact filenames:

- `skrill.png`
- `monstrous_nightmare.png`
- `gronckle.png`
- `hideous_zippleback.png`
- `thunderdrum.png`
- `razorwhip.png`
- `deadly_nadder.png`

These are the seven default starter species currently registered in `lib/dragons.js`. The images are assets for existing species, not new species. Adding images here does not automatically display them in the bot; image-sending code can be connected after uploads.
