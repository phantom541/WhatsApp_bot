# Dragon Bot assets

- `menu/ghost-mascot.svg`: permanent menu banner. The ghost wears a metal bottle-cap crown.
- `colossi_eyes/`: seven separate Eye relic icons.
- `rewards/`: reward artwork and loot icons.
- `dungeons/`, `dungeon_bosses/`, `dungeon_monsters/`, `colossi/`: existing game artwork locations.

SVG files are local assets and can be used directly by Baileys as image buffers after conversion or by serving as files. No remote image dependency is required.
